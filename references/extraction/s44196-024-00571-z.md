Abstract
The objective of the path planning for a mobile robot is to generate a collision-free path from a starting position to a target 
position, aiming to realize a higher quality of path planning, an improved A* algorithm and a hybrid approach incorporat-
ing the dynamic window algorithm have been proposed for robot path planning in various environments in this paper. In 
global path planning, first, a bidirectional search strategy was introduced into to improve the searching efficiency, and an 
adaptive heuristic function was designed to reduce redundant search nodes. In the meantime, a filtering function for key path 
nodes and an enhanced jump point optimization method help to remove redundant nodes in the path, reduce turning angles, 
greatly shorten the path length, and smooth the path using cubic B-spline curves. Furthermore, in local path planning, the 
combination of key path nodes and the dynamic window approach (DWA) algorithm is utilized to achieve obstacle avoid-
ance in dynamic environments and adjust the heading angle of the section enables seamless locomotion of the robot. Finally, 
the simulation experiments and physical experiments on the robot were conducted to validate that the proposed improved 
algorithm significantly improves the speed of path planning while also reducing the length of the planned path and improve 
the reliability of the algorithm when compared with other algorithms.

1  Introduction
With the advancement of technology, reducing manpower 
and resources, improving transportation efficiency, and 
adapting to harsh environments have become challenges 
faced by modern logistics. Mobile robot technology plays 
a crucial role in the contemporary field of warehouse logis-
tics [1, 2]. The hinge of mobile robots lies in path planning 
which includes global path planning and local path planning. 
Among these, global path planning is a static path planning 
referring to find the best path without colliding with obsta-
cles in a known environmental model [3, 4], However, the 
environmental model of local path planning exhibits uncer-
tainty corresponding to practical application environment [5, 
6]. Given the differences of environmental model between 
two path planning, the main algorithms are primarily relied 
upon manifest diversity [7]. In addressing the path plan-
ning problem for robots, numerous scholars have employed 
a variety of approaches and further refined them, including 
Dijkstra algorithm [8], RRT algorithm, ant colony algorithm 
[9] and A* algorithm [10, 11]. However, the current algo-
rithm still suffers from suboptimal path length, extended 
computational runtime, and inapplicability of the generated

2  Environment Model
The A* algorithm is a typical algorithm based on graph 
search in global algorithms, and it has a high level of toler-
ance for processing maps. Whether it is a directed graph 
or an undirected graph, weighted or unweighted edges, all 
graph-based search algorithms can effectively handle path 
planning problems in map environments [23, 24]. In order 
to accurately depict obstacle information in the environ-
ment, utilize grid maps to construct environmental mod-
els. These grid maps can offer precise spatial information, 
with each grid cell capable of representing features such as 
ground type and obstacle data, ensuring a guarantee of pre-
cise depiction of surface characteristics and the distribution 
of objects [25]. Moreover, the dimensions of the grid are 
determined by the size of the robot itself, thereby influencing 
the efficiency and accuracy of the algorithm’s search [26]. 
In this study, in order to enhance the understanding of map 
semantics by robots, the diverse environmental information 
on the map has been categorized into distinct state regions 
as depicted in Fig. 1. Moreover, the robot is considered as 
a point mass, with each grid being defined as a one-unit 
size: white squares represent areas that the mobile robot can 
pass through but has not traversed; black squares symbolize 
the obstacles that the robot cannot navigate through; gray 
squares represent buffer zones between the expanded robot 
and obstacles; green squares represent the starting point; red 
squares represent the target point; yellow squares represent 
the path nodes of the robot; blue squares represent the points 
that the robot has searched.
During the process of path planning using the A* algo-
rithm, the robot is seemed as a point mass and its size 
is considered as a non-collision distance. After attaching 
the constraints to obstacles, considering the possibility 
of the robot scraping or colliding with obstacles in prac-
tice, a higher quality and more accurate motion control 
of the robot would become necessary. In order to address 
this issue, this paper proposes an optimized approach by 
adding a buffer zone around the robot’s size. Therefore, a 
layer of points around the obstacles that the robot cannot 
reach would exist. The robot is depicted as a square grid 
with each side measuring one unit, and the buffer zone is 
set to be 1 layer thick. Through this approach, the path 
should maintain a significant distance from any obstacles 
to ensure safety, ensuring that collisions would not occur 
during actual movement.
Ensuring an establishment of an impeccable framework 
demands a tailored adjustments for the A* algorithm. Gen-
erally, the A* algorithm conducts a search of four neigh-
boring nodes during each expansion, and the turning angle 
is always 90º as depicted in Fig. 2a. However, the effi-
ciency of the robot’s motion is significantly compromised, 
while the turning angle is limited in 90º in practice. In this 
passage, leveraging the employment of 8-neighborhood 
connectivity contributes to enhancing the efficiency and 
performance of path planning. In addition, in Fig. 2b, after 
augmenting the number of adjacent nodes from four to 
eight, the turning angle is not only 90º anymore.

would proceed to choose the node with the least expansion 
cost until reach the target point and gain the optimal path 
[12, 13]. During the search process, the total cost of each 
node is evaluated by adding up g(n) and h(n). The evaluation

In this context, n denotes the node in question; the evalu-
ation function f(n) signifies the aggregate cost associated 
with the node at hand, g(n) articulates the cost incurred in 
traversing from the point of origin to the node under con-
sideration, whereas f(n) is a heuristic function that proffers 
an estimation of the expected expense to reach the destina-
tion from the node currently being evaluated. The evalua-
tion function greatly influences the search process of A* 
algorithm. Moreover, when it comes to selecting a heuristic 
function, there exists several available options. Especially, 
when f(n) = h(n), the A* algorithm would search for opti-
mal path nodes exclusively and thus significantly reduce 
the computation time. Generally, the heuristic function h(n) 
encompasses the Euclidean distance function, the Manhattan 
distance function, and the Chebyshev distance function. In 
this manuscript, we opt for the Euclidean metric as our heu-
ristic function, which calculates the direct distance between 
two coordinate points and is deemed to be more representa-
tive of actual paths than other functions.

3.2  Enhance the Path Planning Algorithms of A* 
and Dynamic Window Approach (DWA)
To remediate the challenges associated with protracted 
computational duration and sluggish retrieval velocity, 
redundant search nodes, non-smooth paths, and inability 
in dynamic environments for fundamental A* algorithm, 
this paper proposes an improved version called IAB-A* 
which combined A* algorithm with the DWA algorithm. 
First, the A* algorithm is enhanced using a bidirectional 
search strategy to reduce computation time. In addition, 
an adaptive heuristic function is introduced to minimize 
redundant search nodes. Furthermore, the resulting path 
is optimized via incorporating jump point optimization, 
effectively reducing its length. Finally, the trajectory is 
refined through B-spline interpolation. In the context of 
local path planning, key path points are extracted and com-
bined with the DWA algorithm to enable obstacle avoid-
ance in dynamic environments.

3.2.1  Bidirectional Search Strategy
The A* algorithm, depicted in Fig. 4a, is a unidirectional 
search algorithm which requires significant computation 
time. To tackle this matter, this manuscript delineates the 
integration of a bidirectional search methodology into the 
framework of the A* algorithm. This approach commences 
the pursuit concurrently from both the origin and the des-
tination, with each path considering the other as its end-
point, resulting in an improved search speed. In addition, 
the search process of advanced A* algorithm is shown in 
Fig. 4b. First, given the starting node and the target node, 
creating two empty open lists for each of them to store the 
nodes to be explored. Simultaneously, two empty closed 
lists are created for the starting node and the target node, 
respectively, to store the nodes that have been explored. 
Commencing from the initial node and the designated 
destination node, the A* algorithm utilizes its heuristic 
function to meticulously explore the most advantageous 
trajectory, guided by the principles of its heuristic cri-
teria. During the search process, when selecting which 
node to be explored, the selected node needs to be checked 
whether has already appeared in the closed list. If the 
answer is yes, it indicates the two directions have met, 
and the shortest path has been found.

3.2.2  Adaptive Heuristic Function
As previously noted, the bidirectional A* algorithm typi-
cally exhibits superior proficiency in the domain of path-
finding relative to its conventional counterpart. However, 
when encountering complex obstacle scenarios, the num-
ber of search nodes in the bidirectional A* algorithm may 
surpass that of the A* algorithm due to f(n) = g(n) + h(n). 
At the beginning of the search, the heuristic value h(n) is 
considerably large due to the considerable distance from 
the target point [27]. With a balanced heuristic function, 
the algorithm tends to prioritize expanding towards the sur-
roundings, conducting a breadth-first search, resulting in 
numerous irrelevant nodes that waste computational time, 
as shown in Fig. 5 and the notable surge in computational 
burden substantially impacts the efficacy of pathfinding. 
The appraisal function stands as an indispensable element 
within the ambit of the bidirectional A* algorithm. A per-
tinent appraisal function not only guarantees the pursuit of 
the most superior trajectory but also curtails the enumeration 
of nodes scrutinized. Consequently, this elevates the algo-
rithm’s proficiency immeasurably. Therefore, an adjustment 
for the heuristic function exhibits necessity.
This manuscript elucidates enhancements to the heuristic 
modality within the bidirectional A* algorithm through the 
dynamic refinement of the heuristic function. Considering 
the distance between robot and obstacles, the adjustment 
of the ratio between g(n) and h(n) in the heuristic func-
tion of both the start and target nodes is determined. This 
approach significantly diminishes the exploration of super-
fluous nodes, thereby enhancing the efficacy of trajectory 
formulation. For instance, when h(n) = 0, utilizing Dijkstra’s 
algorithm to search every grid until the target node is found 
ensures the shortest path. However, this approach results 
in overly redundant node search. Moreover, when the ratio 
between g(n) and h(n) approaches to 1, the A* algorithm 
would emphasize a balance between breadth and depth dur-
ing path planning. When the ratio is greater than 1, the A* 
algorithm may prefer to slow down the search speed, focus-
ing more on details and node expansion. Conversely, when 
the ratio is smaller than 1, the A* algorithm may prioritize 
accelerating the search speed, emphasizing narrowing the 
distance to the target node [28].
As depicted in Fig. 6, l represents the distance between 
the nodes in the buffer zone and the nearest obstacle, and 
di represents the distance between any selected path node 
and its nearest obstacle. Assuming that the distance between 
the robot and the obstacle is exactly equal to the buffer 
zone distance l, the ratio between g(n) and h(n) is set to 
1. When the separation between the robot and the impedi-
ment surpasses the demarcated buffer zone, the distance di 
to the nearest obstacle is calculated, and the ratio between 
l and di serves as the ratio between g(n) and h(n), enabling 
automatic adjustment of the search speed. However, when 
the ratio between g(n) and h(n) becomes excessively large, 
suboptimal search paths may arise. Therefore, this ratio is 
constrained to be within 3, with a maximum ratio of 3. Con-

the ratio between h(n) and g(n) tends towards equilibrium, 
prompting the algorithm to favor an expansive search mode.

The core concept of jump point optimization is to skip 
certain node expansions and evaluations during the search 
process in order to reduce computational load. By identify-
ing and skipping unnecessary nodes in the search process, 
the A* algorithm can find the shortest path more quickly. 
The precise process entails transferring the path nodes 
derived from the A* algorithm, which connects point A 
to point B, into a novel set referred to as P. The starting 
point is labeled as P0, and the numbering continues until 
the destination point, labeled as PG. Starting from ­P0, each 
point is connected to the subsequent points, and the distance 
between the connecting line and the obstacles is compared 
to the distance of a buffer zone. If the distance between P0 
and Pi is smaller than the buffer distance, then the node 
Pi−1 becomes a necessary point and is placed into the set N. 
Furthermore, Pi−1 is updated to become P0, and the process 
of connecting the remaining nodes continues until reaching 
the destination point.

3.2.5  The Integration of the DWA Algorithm for Local Path 
Planning
In addition to perfection of the path planning in a known envi-
ronmental model, the real-world scenarios must be taken into 
account. In the process of practical path planning, there exits 
two main challenges. First, the intended trajectory and its cur-
vature ought to exhibit seamless continuity, ensuring effortless 
navigation for the mobile robot. Second, given the existence of 
dynamic obstacles within the surroundings, it is imperative to 
employ real-time obstacle avoidance. This manuscript deline-
ates a sophisticated, composite algorithm that amalgamates an 
enhanced A* methodology with the dynamic window para-
digm for trajectory strategizing. The standard DWA algorithm 
merely specifies the position of the target point; however, when 
there are numerous obstacles, the path planning algorithm is 
prone to falling into local optima, leading to an increase in 
the overall path length. To address this problem, this paper 
considers the key nodes obtained from the improved A* algo-
rithm’s global path as sub-target points for the local path. By 
decomposing long, complex obstacle environments into mul-
tiple simpler paths, the robot is adept at negotiating unforeseen 
impediments, arriving at the designated coordinates with both 
safety and efficacy. The flowchart can be seen in Fig. 11

3.3  Algorithm Implementation
Based on the principles of the enhanced IAB-A* algorithm 
described above, the precise execution methodology of the 
algorithm is as follows.
	 1.	 Establishing an environmental model
	 2.	 To commence this endeavor, a fundamental step is to 
generate two empty open lists, one pertains to the ori-
gin node while the other corresponds to the destination 
node. Subsequently, the commencement node and the 
objective node are to be inclusively appended to their 
corresponding open lists.
	 3.	 Confirm whether the open list for forward or backward 
search is empty; if not, proceed to step (4). If it is, 
this signifies that upon searching through all reachable 
nodes, if no encounter between forward and backward 
searches has occurred, the path search is considered 
unsuccessful.
	 4.	 Commence bidirectional search: pursuing the objective 
node in the forward direction and the initial node in the 
reverse direction, simultaneously expanding the nodes.
	 5.	 The real-time computing of the distance from the 
robot’s current node to the obstacle updates the heu-
ristic function. The cost value of an expanded node is 
calculated according to formula (5), and neighboring 
nodes are checked to determine if they are obstacles 
or already in the closed list. If they are, the node is 
ignored; if not, the node with the optimal cost value is 
selected, and the cost and parent node information of 
that node are updated.
	 6.	 When encountering duplicate nodes in the CLOSE list 
during bidirectional search, it signifies the discovery of 
a path, and both nodes from the CLOSE lists are added 
to the collection P.
	 7.	 In the set of path nodes, draw connecting lines from the 
starting point one by one, removing nodes that do not 
pass through obstacles, keeping the nodes that through 
obstacles, until reaching the endpoint to obtain key 
path nodes. Then, enhance jump point optimization 
based on each key path node and obstacle position, 
updating the position of key path nodes. Obtain the 
final path critical nodes. If in a static environment, pro-
ceed to step 8; if in a dynamic environment, proceed to 
step 9.
	 8.	 Choose the pivotal waypoints on the essential nodes of 
the path and designate them as control points for the 
B-spline curve, in order to achieve a seamlessly refined 
trajectory.
	 9.	 Utilize the points in the set of key nodes along the 
path as segmented path target points for the DWA algo-
rithm, thereby segmenting the overall path for plan-
ning.
	10.	 Initialize the operational parameters of the DWA algo-
rithm.
	11.	 Calculate the initial angle of departure for the robot 
based on the coordinates of the start and end points of 
the segmented path.
	12.	 Constructing a model of robotic movement. Determine 
the sampling rate space. Determine the evaluation 
function.
	13.	 Select the optimal trajectory.
	14.	 Assemble the segmented paths to create the ultimate 
trajectory for the robot.

5  Conclusions
This study focuses on the environment of small-scale ware-
housing logistics, conducting research on path planning 
for deployed robots. Addressing the issues of global path 
planning and local path planning, improvements are made 
based on the A* algorithm to tackle the shortcomings pre-
sent in path planning with the A* algorithm. We successfully 
realize instantaneous evasion of impediments and corrobo-
rate the practicability of the suggested algorithm through 
empirical applications. The algorithm under consideration 
incorporates a novel bidirectional search methodology that 
alternates directions to augment the efficacy of the path-
finding process. Moreover, the construction of an adaptive 
heuristic function, coupled with a sophisticated enhance-
ment to the jump point optimization technique, successfully 
mitigates the heightened computational demand resulting 
from the diminution of superfluous search nodes. Moreo-
ver, the reduced turning angle and a smooth path length are 
obtained via cubic B-spline curves. The final route planning 
time is reduced by 50%, and the route length is reduced 
by around 5%. In addition, considering the practical diffi-
culty of acquiring perfect situational awareness during local 
path planning, integrating with DWA algorithm is a proven 
solution to generate collision-free smooth paths in dynamic 
obstacle environments. The empirical outcomes observed 
within various grid settings affirm that the algorithm pre-
sented herein markedly enhances the rapidity of the navi-
gational route formulation while concurrently abbreviating 
the extent of the trajectory. Physical experiments validate 
the feasibility of the proposed algorithm in practical appli-
cations and demonstrate notable improvement in execution 
speed compared to similar grid-based mapping algorithms. 
The performance of the algorithm is superior to traditional 
approaches and is suitable for obstacle environments under 
various conditions, as indicated by the simulation experi-
ments. The advantage of the proposed method in this paper 
lies in its excellent path quality and real-time performance; 
however, there is an issue in the local path planning algo-
rithm that integrates the DWA algorithm, which involves 
long computation time and the inability to handle a path as 
a whole. Future research tends to lean towards using intel-
ligent algorithms to collectively address both global and 
local path planning issues. The further work will focus on 
optimizing the algorithm in collaborative settings involving 
multiple robots instead of being limited in single robot path 
planning.
